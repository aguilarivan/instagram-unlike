01 — export

Exportá tus datos

Instagram permite descargar tu historial completo de likes. El script necesita únicamente el archivo liked_posts.json en formato JSON.

01
Crear el export
Ir a Instagram → Perfil → Menú (☰) → Accounts Center → Your information and permissions → Download your information → Create export
02
Seleccionar “Export to device”
Elegí exportar los datos directamente a tu dispositivo, no a un servicio externo.
03
Exportar únicamente Likes
En Customize information, destildá todo y dejá solamente Likes. Esto hace que el export sea mucho más rápido y liviano.
04
Elegir formato JSON
Seleccioná JSON, no HTML. El script no puede parsear exports HTML.
05
Esperar el email
Instagram procesa el export en minutos o hasta 48hs. Después descargás un ZIP con tus datos.
06
Extraer liked_posts.json
Descomprimí el ZIP y buscá: your_instagram_activity/likes/liked_posts.json
02 — explorar

stats.py

Antes de borrar nada, explorá el JSON. Te dice cuántos likes tenés, distribución por año, top usuarios y tipo de contenido.

stats.pypython
import json
from datetime import datetime
from collections import Counter

with open('liked_posts.json', 'r', encoding='utf-8') as f:
    likes = json.load(f)

urls, usernames, years = [], [], []

for item in likes:
    for lv in item.get('label_values', []):
        if lv.get('label') == 'URL' and lv.get('href'):
            urls.append(lv['href'])
    for lv in item.get('label_values', []):
        if isinstance(lv.get('dict'), list):
            for d in lv['dict']:
                for inner in d.get('dict', []):
                    if inner.get('label') == 'Username' and inner.get('value'):
                        usernames.append(inner['value'])
    ts = item.get('timestamp')
    if ts:
        years.append(datetime.fromtimestamp(ts).year)

print(f"\n{'='*40}")
print(f"  Total likes: {len(urls)}")
print(f"{'='*40}")
print("\nPor año:")
for year, count in sorted(Counter(years).items()):
    print(f"  {year}: {count}")
print("\nTop 10 usuarios:")
for user, count in Counter(usernames).most_common(10):
    print(f"  @{user}: {count}")
print("\nTipos:")
reels = sum(1 for u in urls if '/reel/' in u)
posts = sum(1 for u in urls if '/p/' in u)
print(f"  Reels: {reels} | Posts: {posts} | Otros: {len(urls)-reels-posts}")

03 — sesión

save_session.js

Guardá tu login una sola vez. El script principal reutiliza las cookies automáticamente sin pedirte contraseña cada vez.

save_session.jsjavascript
const { chromium } = require('playwright');

(async () => {
  const browser = await chromium.launch({ headless: false });
  const context = await browser.newContext();
  const page    = await context.newPage();

  await page.goto('https://www.instagram.com/');
  console.log('Hacé login y presioná Enter...');
  await new Promise(r => process.stdin.once('data', r));

  await context.storageState({ path: 'session.json' });
  console.log('Sesión guardada en session.json ✓');
  await browser.close();
})();

04 — unlike

unlike.js

El script principal. Pasale cuántos likes borrar en esta sesión. Retoma automáticamente desde el último checkpoint guardado en progress.json.

unlike.jsjavascript
const { chromium } = require('playwright');
const fs = require('fs');

const PROGRESS_FILE = 'progress.json';
const LIKES_FILE    = 'liked_posts.json';
const SESSION_FILE  = 'session.json';
const LIMIT         = parseInt(process.argv[2]) || 10;
const MIN_WAIT      = 8000;
const MAX_WAIT      = 20000;

function sleep(ms) { return new Promise(r => setTimeout(r, ms)); }
function rand(min, max) { return Math.floor(Math.random() * (max - min + 1)) + min; }

function loadProgress() {
  if (fs.existsSync(PROGRESS_FILE))
    return JSON.parse(fs.readFileSync(PROGRESS_FILE, 'utf8'));
  return { done: [], failed: [] };
}
function saveProgress(p) {
  fs.writeFileSync(PROGRESS_FILE, JSON.stringify(p, null, 2));
}

const likes   = JSON.parse(fs.readFileSync(LIKES_FILE, 'utf8'));
const allUrls = likes
  .flatMap(item => item.label_values || [])
  .filter(lv => lv.label === 'URL' && lv.href)
  .map(lv => lv.href);

const progress = loadProgress();
const pending  = allUrls
  .filter(u => !progress.done.includes(u) && !progress.failed.includes(u))
  .slice(0, LIMIT);

console.log(`\nTotal en JSON:    ${allUrls.length}`);
console.log(`Ya procesados:    ${progress.done.length}`);
console.log(`Esta sesión:      ${pending.length}`);
console.log(`Pendientes total: ${allUrls.length - progress.done.length - progress.failed.length}\n`);

(async () => {
  const browser = await chromium.launch({
    headless: false,
    args: ['--disable-blink-features=AutomationControlled']
  });
  const context = await browser.newContext({
    storageState: SESSION_FILE,
    userAgent: 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36',
    viewport: { width: 1280, height: 800 },
    locale: 'es-AR',
  });
  const page = await context.newPage();

  await page.addInitScript(() => {
    Object.defineProperty(navigator, 'webdriver', { get: () => undefined });
  });

  for (let i = 0; i < pending.length; i++) {
    const url = pending[i];
    console.log(`\n[${i + 1}/${pending.length}] ${url}`);

    try {
      let loaded = false;
      for (let attempt = 0; attempt < 3; attempt++) {
        try {
          await page.goto(url, { waitUntil: 'domcontentloaded', timeout: 20000 });
          loaded = true;
          break;
        } catch {
          console.log(`  Reintentando (${attempt + 1}/3)...`);
          await sleep(3000);
        }
      }
      if (!loaded) {
        progress.failed.push(url);
        console.log(`  ✗ No se pudo cargar`);
        saveProgress(progress);
        continue;
      }

      try {
        await page.waitForSelector(
          'svg[aria-label="Ya no me gusta"], svg[aria-label="Unlike"]',
          { timeout: 8000 }
        );
      } catch {}

      await sleep(rand(1500, 2500));
      await page.mouse.move(rand(300, 700), rand(200, 500));
      await sleep(rand(200, 500));
      await page.mouse.move(rand(400, 600), rand(300, 450));
      await sleep(rand(100, 300));

      const likedBtn = page.locator(
        'svg[aria-label="Ya no me gusta"], svg[aria-label="Unlike"]'
      ).first();

      if (await likedBtn.count() > 0) {
        await likedBtn.click();
        progress.done.push(url);
        console.log(`  ✓ Unlike OK`);
      } else {
        console.log(`  - Corazón no encontrado, queda pendiente`);
      }

    } catch (e) {
      progress.failed.push(url);
      console.log(`  ✗ Error: ${e.message}`);
    }

    saveProgress(progress);

    if (i < pending.length - 1) {
      const wait = rand(MIN_WAIT, MAX_WAIT);
      console.log(`  Esperando ${(wait / 1000).toFixed(1)}s...`);
      await sleep(wait);
    }
  }

  console.log(`\n✓ Sesión terminada.`);
  console.log(`Procesados hoy: ${pending.length} | Acumulado: ${progress.done.length} | Fallos: ${progress.failed.length}`);
  await browser.close();
})();

ANTI-BOT
Pausas aleatorias
8 a 20 segundos entre cada unlike. Sin patrón fijo detectable por Instagram.
CHECKPOINT
Progreso incremental
Guarda cada URL procesada al instante. Si cortás el script, retoma solo.
RETRY
Reintentos automáticos
Si una página no carga, reintenta 3 veces antes de saltear y seguir.
STEALTH
Anti-detección
webdriver oculto, user agent real de Chrome, movimientos de mouse simulados.
Nota sobre idioma: el aria-label del botón varía según el idioma de tu cuenta. En español es "Ya no me gusta", en inglés "Unlike". El script maneja ambos. Si usás otro idioma, inspeccioná el corazón con DevTools (F12) y ajustá el selector en las dos líneas donde aparece.
